# Linear Antennas Analysis in 4nec2(Numerical Electromagnetics Code) software

The assignment was part of the course Antennas &amp; Propagation (Electrical &amp; Computer Engineering, Aristotle University of Thessaloniki)

This repository contains all the .nec files for building the antennas' structures, the resulting diagrams and the final report. 

## Overview
### For the following Antennas:
1.Discone Antenna

2.Helix Antenna

3a.Folded Dipole - for various wire spacings

3b.Traveling Wave Antenna - over Perfect & Good Ground

Using 4nec2 software:
- design of the structure, input impedence & reflection coefficient
- horizontal, vertical & 3D radiation patterns for different frequencies, intrpretation of the resutls
